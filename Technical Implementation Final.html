Module One

API Security

Only verified, authorised, and well-behaved systems can reach Mastercard APIs.

mTLS OAuth 2.0 Rate Limiting SIEM Monitoring
Four Controls

How We Secure Every API Call

Identity, permission, volume, and visibility all four working together.

Control 1 mTLS (Identity)

Both sides prove who they are

Unlike standard HTTPS (server-only cert), mTLS requires the client to present a certificate too. No valid cert = connection refused before any data moves. Certs rotate every 90 days.

Control 2 OAuth 2.0 (Permission)

Short-lived tokens limit what's possible

JWT tokens carry scope (what's allowed), audience (which API), and expiry (15 min). A system that can read transaction status cannot trigger payments different scopes.

Control 3 Rate Limiting (Volume)

100 req/min per client, 429 on exceed

Caps abuse and enumeration attacks. Anomaly detection adds a second layer if traffic spikes >20% above baseline, SIEM alerts immediately even if under the rate cap.

Control 4 Logging (Visibility)

Every call logged, 90-day retention

All API activity flows to SIEM in real time. Without logs, you cannot investigate an incident. 90 days is the PCI DSS minimum.

Deliverable 2 + PCI Mapping

The HSM Vault & Compliance Alignment

HSM — Hardware Security Module

Encryption keys physically trapped inside

FIPS 140-2/3 compliant. Keys are generated and used inside the HSM — they never exit in plaintext. AES-256 encrypts all stored PANs. Even someone with full server access cannot extract the keys.

Token Design — Irreversible

Non-deterministic: no formula exists

Same PAN tokenized twice → two completely different, unrelated tokens. You cannot reverse-engineer the PAN from a token. The only path back is through the vault — which requires breaking through every access control.

The Three Layers How They Work Together

No single failure is catastrophic. Each layer catches what the previous one missed.

Layer 1 API Security

mTLS + OAuth + Rate Limiting

If this layer fails, the attacker still finds only tokens no real PANs.

Layer 2 Tokenization

Real-time PAN → Token

If tokenization is breached, the network layer means the attacker can't reach the vault.

🌐
Layer 3 Network

Default Deny + CDE Isolation

Even if they reach the vault, HSM keys physically cannot be extracted by software.
